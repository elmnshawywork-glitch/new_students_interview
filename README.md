# منظومة قبول المدارس التكنولوجية التطبيقية

نظام ويب لتسجيل الطلاب، وإجراء امتحان لغوي مُصحَّح بالذكاء الاصطناعي، وتقييم المقابلة الشخصية، ثم حساب الدرجة النهائية.

- **الواجهة (Frontend):** HTML/CSS/JavaScript ثابت — يعمل على GitHub Pages أو أي استضافة، بدون خطوة بناء.
- **قاعدة البيانات + الـ API (Backend):** Google Apps Script فوق Google Sheet الخاص بك.
- **التصحيح الآلي:** عبر Claude API (مفتاحك الخاص).
- **الدرجة النهائية:** 50% مقابلة + 30% امتحان الوحدة + 20% الامتحان اللغوي.

> يمكنك تجربة النظام فورًا **بدون أي إعداد** عبر *الوضع التجريبي* (انظر الأسفل).

---

## 1) تجربة سريعة (وضع تجريبي بدون خادم)

1. افتح `frontend/index.html` في المتصفح (أو انشر مجلد `frontend` على GitHub Pages).
2. تأكد أن `BACKEND_URL` في `frontend/config.js` فارغ `""`.
3. سجّل الدخول بحساب تجريبي:
   - مدير البرنامج: `admin` / `ebda2026`
   - أعضاء لجنة المقابلة (كلمة المرور الافتراضية `123456`): `ats` (وحدة المدارس التكنولوجية) — `aca` (الشريك الأكاديمي) — `ind` (الشريك الصناعي)

في الوضع التجريبي تُخزَّن البيانات في ذاكرة المتصفح فقط (تُمسح عند التحديث)، والتصحيح يتم بخوارزمية بسيطة بدل الذكاء الاصطناعي.

---

## 2) التشغيل الحقيقي على Google Sheet

### أ. تجهيز قاعدة البيانات (Apps Script)
1. افتح Google Sheet الخاص بك ثم: **Extensions ← Apps Script**.
2. أنشئ ملفين والصق محتواهما:
   - `Code.gs` ← من `backend/Code.gs`
   - `Passages.gs` ← من `backend/Passages.gs`
3. من قائمة الدوال شغّل `setup()` مرة واحدة، ووافق على الصلاحيات.
   - تُنشأ التبويبات: `Users, Config, Students, UnitGrades, LangResults, Interviews, Passages`.
   - تُنشأ الحسابات: مدير `admin` / `ebda2026`، وأعضاء لجنة `ats` و`aca` و`ind` بكلمة مرور `123456` (غيّرها من تبويب Users).
   - تُزرع 55 قطعة تلقائيًا في تبويب `Passages`.

### ب. نشر الـ Web App
1. **Deploy ← New deployment ← Web app**.
2. الإعدادات: *Execute as:* **Me** — *Who has access:* **Anyone**.
3. انسخ رابط الـ Web app (ينتهي بـ `/exec`).
4. الصق الرابط في `frontend/config.js`:
   ```js
   window.APP_CONFIG = { BACKEND_URL: "https://script.google.com/macros/s/XXXX/exec", ... };
   ```

### ج. تفعيل التصحيح بالذكاء الاصطناعي (اختياري لكن مُوصى به)
1. احصل على مفتاح من [Anthropic Console](https://console.anthropic.com/).
2. في Apps Script: **Project Settings ← Script Properties ← Add property**
   - الاسم: `ANTHROPIC_API_KEY` — القيمة: مفتاحك.
3. الموديل الافتراضي `claude-haiku-4-5` (سريع ورخيص). لدقة ترجمة أعلى غيّره في `Code.gs` إلى `claude-sonnet-4-5`.

> بدون مفتاح، يعمل النظام بالتصحيح الآلي المبسّط (تطابق الكلمات) تلقائيًا.

## 3) الرفع على GitHub

**الطريقة (أ) — عبر أوامر Git:**

```bash
cd project
git init
git add .
git commit -m "منظومة قبول المدارس التكنولوجية التطبيقية"
git branch -M main
git remote add origin https://github.com/<اسم-حسابك>/<اسم-المستودع>.git
git push -u origin main
```

**استضافة الواجهة على GitHub Pages:** Settings ← Pages ← اختر الفرع `main` والمجلد `/frontend` (أو انقل ملفات `frontend` إلى الجذر). لا ترفع أي مفتاح API إلى GitHub — المفتاح يبقى داخل Script Properties فقط.

**الطريقة (ب) — بدون أوامر (سحب وإفلات):**
1. أنشئ مستودعًا جديدًا على github.com (زر New).
2. اضغط **Add file ← Upload files**، ثم اسحب محتويات مجلد المشروع (بعد فك الضغط) وأفلتها.
3. اضغط **Commit changes**.
4. لتشغيل الواجهة كموقع: Settings ← Pages ← اختر `main` والجذر، وافتح الرابط الذي يظهر.

## 4) تنسيق ملفات Excel (للاستيراد)

**بيانات الطلاب:** الاسم الرباعي، الرقم القومي (14 رقمًا)، المدرسة المتقدَّم عليها، موبايل الطالب، موبايل ولي الأمر، الايميل. يمكنك تحديد **اسم عمود كل حقل** من صفحة الإعدادات (رؤوس أعمدة ملف الاستيراد) لمطابقتها مع ملفك، مع مطابقة ذكية احتياطية.

**درجات امتحان الوحدة:** الاسم و/أو الرقم القومي، الدرجة. إذا خلا الصف من الرقم القومي يُربَط تلقائيًا بالاسم.

> رفع بيانات الطلاب من Excel لا يظهر إلا إذا فعّلته من **الإعدادات**. المدارس تُدار من الإعدادات وتظهر كقائمة منسدلة مع خيار «أخرى» للإضافة اليدوية.

## 5) طريقة الحساب

- **الامتحان اللغوي (20%):** ثلاثة أقسام — استماع إنجليزي (٣ جمل قصيرة لمستوى المبتدئ، بصوت رجالي واضح)، ترجمة إنجليزي→عربي، استماع عربي (فصحى مشكّلة بلهجة مصرية) — تُنطق جملةً جملةً مع مهلة قابلة للضبط لإتاحة وقت الكتابة، وكل طالب يحصل على قطع عشوائية مختلفة. **لا يُسمح للطالب بأداء الامتحان أكثر من مرة**؛ ويمكن لمدير البرنامج فقط إعادة فتحه في حال وجود مشكلة. تُحفظ **أسئلة وإجابات المتقدّم** ويمكن **طباعتها** للمدرسة من بطاقة درجات الطالب (شاشة النتائج) عند الحاجة (مثل الشكاوى).
- **امتحان الوحدة (30%):** درجة خارجية تُدخل يدويًا أو تُرفع من Excel.
- **المقابلة (50%):** مؤشرات قابلة للإضافة/التعديل يقيّمها كل عضو لجنة، وتُؤخذ **متوسط** نِسَب من شاركوا فعليًا (عضو واحد أو أكثر). عند دخول عضو اللجنة يرى **تبويبين فقط**: «تقييم المقابلة» و«تقرير» (تبويب الامتحان اللغوي لا يظهر له). وعند اختيار الطالب تظهر درجاته في امتحان الوحدة والامتحان اللغوي **بالتفصيل والإجمالي**، ثم عناصر تقييم المقابلة، وبعد الحفظ تظهر الدرجة الكلية وحالة القبول.

**تبويب التقرير:** فلترة النتائج (بالاسم/الرقم القومي، المدرسة، يوم الامتحان، الحالة، وحد أدنى لأي امتحان: وحدة/لغوي/مقابلة/الكلية)، ثم تصدير **Excel / PDF / Word**، إضافةً إلى **«تصدير ملف الوحدة»** ككشف بصيغة الوحدة (مقبول / علي قائمة الانتظار) مرتّب تنازليًا.

**ملاحظة التصحيح:** الترجمة والاستماع الإنجليزي يُصحَّحان **حسب المعنى والسياق** لا حرفيًّا، والاستماع العربي **لا يُحاسب** على التنوين أو علامات الترقيم أو التشكيل.

**ملحوظة القبول:** اجتياز درجة القبول لا يعني الالتحاق مباشرةً؛ يتم عمل تنسيق بترتيب من اجتازوا من الأعلى للأقل واختيار الأفضل. الأوزان ودرجة القبول قابلة للتعديل من الإعدادات (مجموع الأوزان = 100).

> من شاشة **النتائج** يمكن الضغط على **«تصدير المجتازين (Excel)»** لتنزيل ملف يحتوي فقط من اكتمل تقييمهم واجتازوا درجة القبول، مرتّبين تنازليًا حسب الدرجة الكلية مع ترقيم الترتيب — لاستخدامه في التنسيق.

## 6) بنية المشروع

```
project/
├── frontend/
│   ├── index.html      # الصفحة الرئيسية
│   ├── styles.css      # التصميم (RTL)
│   ├── config.js       # رابط الـ backend وإعدادات عامة
│   ├── api.js          # عميل الـ API + محاكي الوضع التجريبي
│   ├── app.js          # منطق الشاشات
│   └── passages.js     # بنك القطع (للوضع التجريبي)
├── backend/
│   ├── Code.gs         # الـ API + التصحيح الآلي
│   └── Passages.gs     # بنك القطع لزرعه في الشيت
├── data/
│   └── passages.json   # بنك القطع (55) بصيغة JSON
└── README.md
```
